# 霜港工坊

这是 M2 端到端验收（`e2e-tests/m2-end-to-end`）的**副本 A**夹具。

它存在的意义：让验收脚本有一个**真实的第二个副本**——
每个副本有各自的 `.stratix` 契约面（`project.json` / `config/stratix.json` / `roster/`），
于是「契约 → 运行层」的单向物化（步 N6）真的发生：
副本 A 物化出 `scout` / `medic` 两行，副本 B 物化出 `scout` / `engineer` 两行，
**同名角色在两个副本里是两行、两个 id、各自养成**。

夹具里除契约面外**不含任何数据** —— 数据由验收脚本在临时库里现造。
