## 实现方案

1. 在 `src/stratix-rts/buildings/Building.ts` 中：
```typescript
export class Building extends Phaser.GameObjects.Container {
  private roomsContainer: Phaser.GameObjects.Container;
  private buildingShell: Phaser.GameObjects.Container;  // 屋顶
  
  constructor(scene: Phaser.Scene, config: BuildingConfig) {
    super(scene, config.x, config.y);
    this.createBuildingStructure();
  }
  
  public showInterior(): void {
    // 显示格子间
    this.roomsContainer.setVisible(true);
    // 隐藏屋顶
    this.buildingShell.setVisible(false);
  }
  
  public hideInterior(): void {
    // 隐藏格子间
    this.roomsContainer.setVisible(false);
    // 显示屋顶
    this.buildingShell.setVisible(true);
  }
}
```

2. 在 TaskZone 中监听选中事件：
```typescript
// TaskZone 的 select/deselect 方法中调用 Building
public select(): void {
  super.select();
  this.building?.showInterior();
}

public deselect(): void {
  super.deselect();
  this.building?.hideInterior();
}
```

## 测试用例
- 选中 Zone 时屋顶消失、格子间可见
- 取消选中时屋顶出现、格子间不可见
