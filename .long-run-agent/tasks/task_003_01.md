## 概述

扩展 Zone 数据模型，在 ProjectZoneConfig 中新增 buildingType 字段

## 技术栈

TypeScript

## 输入输出

### 输入
- 现有 `src/stratix-project/types.ts` 中的 `ProjectZoneConfig` 接口
- 5 种建筑类型枚举：data-center, workshop, studio, library, command

### 输出
- 扩展后的 `ProjectZoneConfig` 接口（包含 buildingType 字段）
- 更新后的 Zone API 支持 buildingType 参数

## 实现方案

1. 在 `src/stratix-project/types.ts` 中定义建筑类型枚举：
```typescript
export enum BuildingType {
  DataCenter = 'data-center',
  Workshop = 'workshop',
  Studio = 'studio',
  Library = 'library',
  Command = 'command'
}
```

2. 扩展 `ProjectZoneConfig` 接口：
```typescript
export interface ProjectZoneConfig {
  x: number;
  y: number;
  width: number;
  height: number;
  color?: number;
  opacity?: number;
  visible?: boolean;
  buildingType?: BuildingType;  // 新增
  buildingState?: 'empty' | 'active' | 'busy' | 'full' | 'error';  // 新增（派生）
}
```

3. 更新 Zone API 路由（`src/stratix-gateway/api/routes/zone.ts`）：
   - `POST /api/zones` 请求体支持 `buildingType` 字段（可选）
   - `PATCH /api/zones/:id` 支持 `buildingType` 更新
   - `GET /api/zones/:id` 响应包含 `buildingType`

4. 更新 `ZoneService.ts` 中的 create/update 方法，支持 config 中的 buildingType

- 更新 Zone 的 buildingType，正确更新
