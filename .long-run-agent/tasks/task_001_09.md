## 实现方案

### 1. ZoneTemplateManager 类实现
- 模板注册和管理（registerTemplate, unregisterTemplate, getTemplate）
- 模板应用功能（applyTemplate 支持位置缩放和自定义尺寸）
- 模板序列化/反序列化（serializeTemplate, deserializeTemplate）
- 模板验证（validateTemplate 检测缺失字段、重叠位置等）
- 自定义模板管理（saveCustomTemplate, deleteCustomTemplate）
- 模板导入导出（exportTemplates, importTemplates）
- 从现有Zone创建模板（createTemplateFromZones）

### 2. 预设模板库实现
创建了10个预设模板，分为4个类别：
- **Grid（网格）**: Grid 2x2, Grid 3x3
- **Linear（线性）**: Horizontal Line, Vertical Line, Documentation Workflow
- **Circular（环形）**: Circular 4 zones, Circular 8 zones
- **Custom（自定义）**: Code Review Setup, Parallel Processing, T-Shape Layout

### 3. 撤销重做支持
- TemplateApplicationAction 实现 ZoneAction 接口
- 与现有 ZoneHistory 系统集成
- 支持模板应用的撤销和重做

### 4. 集成类
- ZoneTemplateIntegration 提供统一接口
- 自动注册所有内置模板
- 支持带历史记录的模板应用
