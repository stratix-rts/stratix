## 概述

创建 Zone 类型选择 UI 组件，用户画框后弹出选择建筑类型

## 技术栈

Vue 3, TypeScript, Design System

## 输入输出

### 输入
- Zone 画框完成的坐标和尺寸
- 5 种建筑类型：data-center, workshop, studio, library, command

### 输出
- ZoneTypeSelector.vue 组件
- 选择建筑类型后的事件回调

## 实现方案

1. 创建 `src/stratix-rts/ui/ZoneTypeSelector.vue` 组件

2. 组件功能：
   - 显示 5 个建筑类型按钮（带图标和名称）
   - 点击任意类型后关闭组件并触发回调
   - 支持 ESC 键关闭
   - 样式使用 design-system tokens

3. 每个类型显示：
   - 图标（emoji 或 svg）
   - 名称（中文）
   - 简短描述（可选）

4. 在 StratixRTSUIScene 中集成：
   - Zone 创建画框完成后显示 ZoneTypeSelector
   - 用户选择类型后调用 Zone API 创建 Zone（带 buildingType）
   - 选择后创建 Building 对象

## 测试用例
- 画框后正确弹出类型选择器
- 点击类型后正确触发回调
- ESC 关闭
- 样式符合 design-system
