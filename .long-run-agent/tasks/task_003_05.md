## 实现方案

1. 创建 `src/stratix-rts/buildings/types/BuildingState.ts`：
```typescript
export enum RoomState {
  Empty = 'empty',
  Occupied = 'occupied'
}
```

2. 创建 `src/stratix-rts/buildings/Room.ts`：
```typescript
export interface RoomConfig {
  x: number;
  y: number;
  width: number;
  height: number;
  agentId?: string;  // 如果有 Agent 占据
  state: RoomState;
}

export class Room extends Phaser.GameObjects.Container {
  private config: RoomConfig;
  
  constructor(scene: Phaser.Scene, config: RoomConfig) {
    super(scene, config.x, config.y);
    this.config = config;
  }
  
  public assignAgent(agentId: string): void {
    this.config.agentId = agentId;
    this.config.state = RoomState.Occupied;
  }
  
  public unassignAgent(): void {
    this.config.agentId = undefined;
    this.config.state = RoomState.Empty;
  }
  
  public getConfig(): RoomConfig {
    return this.config;
  }
}
```

3. 格子间布局算法：
- 根据 Zone 尺寸和 Agent 数量计算格子间数量
- 格子间大小自适应（最小 48×48，最大 96×96）
- 网格排列
