## 实现方案

### 核心组件

1. **ZoneConnection** (`src/stratix-rts/zones/ZoneConnection.ts`)
   - 连接数据模型，包含源Zone、目标Zone、连接类型、元数据等
   - 支持5种连接类型：sequential、parallel、conditional、loop、branch
   - 提供序列化/反序列化功能

2. **ZoneConnectionManager** (`src/stratix-rts/zones/ZoneConnectionManager.ts`)
   - 管理所有Zone连接关系
   - 提供创建、删除、查询、更新连接的方法
   - 支持连接验证（自连接、循环检测）
   - 提供图操作API（构建连接图、路径查找、循环检测）

3. **ConnectionRenderer** (`src/stratix-rts/zones/ConnectionRenderer.ts`)
   - 使用Phaser Graphics绘制连接线
   - 支持直线和贝塞尔曲线绘制
   - 不同连接类型的视觉样式（颜色、虚线、箭头）
   - 支持连接线动画效果

4. **WorkflowVisualizer** (`src/stratix-rts/zones/WorkflowVisualizer.ts`)
   - 工作流定义和管理
   - 工作流执行状态跟踪（idle、running、paused、completed、failed）
   - 工作流进度计算
   - 工作流可视化（节点和边）

5. **ConnectionActions** (`src/stratix-rts/zones/ConnectionActions.ts`)
   - 支持撤销/重做的连接操作
   - 集成ZoneHistory系统
   - 发送RTSEvent事件

### 连接类型支持

1. **Sequential**: 顺序连接（实线，蓝色）
2. **Parallel**: 并行连接（虚线，绿色）
3. **Conditional**: 条件连接（短虚线，橙色）
4. **Loop**: 循环连接（点划线，紫色）
5. **Branch**: 分支连接（点线，红色）

### 工作流功能

- 创建工作流定义
- 启动/暂停/恢复工作流
- 步骤完成/失败处理
- 进度跟踪
- 工作流克隆和重置

  ['zone-1', 'zone-2', 'zone-3']

workflowVisualizer.completeStep('wf-1', 'zone-1');
const progress = workflowVisualizer.getWorkflowProgress('wf-1');
