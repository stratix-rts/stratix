# 阶段2: AI任务拆分系统

## 📋 阶段目标

实现AI自动解析需求、拆分任务区的核心功能，这是整个系统的"智能大脑"。

**预计工期**: 3-4周

**核心价值**: 用户提交需求后，AI自动拆分任务区、设置依赖关系、分配优先级，大幅降低用户操作成本。

---

## 🎯 功能清单

### 核心功能
- ✅ 需求提交接口（一句话 + MD文档上传）
- ✅ AI服务接口（支持多种LLM）
- ✅ 需求解析器（RequirementParser）
- ✅ 任务拆分器（TaskSplitter）
- ✅ 任务区自动生成
- ✅ 依赖关系可视化（连线显示）
- ✅ 蓝图预览界面
- ✅ 蓝图微调功能

### 技术任务
1. 实现AI服务提供者接口
2. 实现OpenAI/CLaude/Ollama适配器
3. 实现需求解析逻辑
4. 实现任务拆分算法
5. 创建蓝图画布（BlueprintCanvas）
6. 实现依赖关系连线
7. 实现蓝图预览与编辑

## 📝 关键决策

### 决策1: AI服务选择
**选择**: 支持多种LLM，用户自己配置
**实现**: 
- 统一接口 AIServiceProvider
- 工厂模式创建不同实现
- 配置文件管理API密钥

### 决策2: 需求解析策略
**选择**: 使用Prompt Engineering
**实现**:
- 结构化输出（JSON Schema）
- Few-shot learning
- 错误重试机制

### 决策3: 蓝图可视化
**选择**: Phaser 3 Canvas
**原因**:
- 与现有RTS界面一致
- 高性能渲染
- 支持复杂交互
