# 阶段1: 项目区基础架构

## 📋 阶段目标

实现最核心的"画框创建项目"功能，为整个项目管理系统打下基础。

**预计工期**: 2-3周

**核心价值**: 用户可以通过画框创建项目，配置基础信息，实现项目的可视化管理。

---

## 🎯 功能清单

### 核心功能
- ✅ 项目区绘制（继承现有绘制逻辑）
- ✅ 项目配置面板（名称、优先级、本地文件夹）
- ✅ 项目数据存储（基于lowdb）
- ✅ 项目区可视化（边框、名称、状态）
- ✅ 项目列表管理（创建、读取、更新、删除）
- ✅ 项目区拖拽与缩放
- ✅ 项目状态标识（未启动、执行中、已完成）

### 技术任务
1. 重构现有 TaskZone 为基础类
2. 创建 ProjectZone 类（扩展 TaskZone）
3. 实现项目配置面板（Vue组件）
4. 实现项目管理器（ProjectManager）
5. 实现项目存储（ProjectStore）
6. 集成到现有RTS游戏场景

## 📝 关键决策

### 决策1: ProjectZone 继承方案
**选择**: 继承 Phaser.GameObjects.Container
**原因**: 
- 保持与现有架构一致
- 方便添加子对象（任务区）
- 支持拖拽、缩放等交互

### 决策2: 数据存储方案
**选择**: 继续使用 lowdb
**原因**:
- 技术栈一致
- 简单可靠
- JSON文件易于备份

### 决策3: 配置面板实现
**选择**: Vue 3 组件
**原因**:
- 与英雄设计器保持一致
- 组件化开发
- 响应式数据绑定
