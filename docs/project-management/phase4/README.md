# 阶段4: 5种任务类型差异化配置

## 📋 阶段目标

实现写作、编程、画图、视频、研究5种任务类型的专属配置和执行逻辑。

**预计工期**: 3-4周

**核心价值**: 不同任务类型有对应的配置界面和执行逻辑，提升AI执行精准度。

---

## 🎯 功能清单

### 核心功能
- ✅ 任务类型注册表
- ✅ 专属配置文本框（每种类型）
- ✅ MD文档上传与解析
- ✅ Git协同配置（编程类）
- ✅ 素材关联（写作、视频、研究）
- ✅ 任务类型切换
- ✅ 类型专属执行逻辑

### 5种任务类型
1. **写作类**: 文档撰写、内容创作
2. **编程类**: 代码开发、Git协同
3. **画图类**: 图标设计、图层管理
4. **视频类**: 视频剪辑、素材处理
5. **研究类**: 资料分析、报告生成

## 📝 关键特性

### 写作类
- 专属配置: 格式选择（MD/HTML/Plain）
- 素材关联: 支持关联情报、笔记
- 实时预览: 写作过程实时显示
- 输出格式: 自动转换格式

### 编程类
- Git协同: 自动提交代码
- 权限管控: 可限制执行/测试权限
- 分支管理: 支持多分支
- 代码审查: 生成提交日志

### 画图类
- 图层管理: 多图层绘制
- 尺寸配置: 自定义尺寸
- 格式支持: PNG/JPG/SVG
- 本地缓存: 中间成果缓存

### 视频类
- 素材关联: 视频片段、音频
- 剪辑配置: 时长、分辨率
- 格式支持: MP4/MOV/AVI
- 进度管控: 详细进度显示

### 研究类
- 资料来源: 本地PDF、Git仓库
- 批量处理: 多文档处理
- 输出格式: 摘要/报告/分析
- 交互反馈: 点击跳转原文
