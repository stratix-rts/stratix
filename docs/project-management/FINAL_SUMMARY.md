## 🏗️ 架构设计

### 分层架构

```
┌─────────────────────────────────────┐
│     用户界面层 (Vue Components)      │
│   - ProjectConfigPanel              │
│   - ProjectListPanel                │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│      场景层 (Phaser Scene)           │
│   - ProjectManagementExampleScene   │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│    集成层 (Integration Layer)        │
│   - ProjectManagerIntegration       │
│   - ProjectZonePreview              │
└──────────────┬──────────────────────┘
               │
        ┌──────┴──────┐
        ▼             ▼
┌──────────────┐ ┌───────────────┐
│  业务逻辑层   │ │  可视化层      │
│  Manager     │ │  Zone         │
└──────┬───────┘ └───────────────┘
       │
       ▼
┌─────────────────────────────────────┐
│      数据持久化层 (lowdb)             │
│   - ProjectStore                    │
└─────────────────────────────────────┘
```

### 数据流

```
用户操作 → 场景 → 集成层 → Manager → Store → JSON 文件
                ↓
           ProjectZone (可视化更新)
                ↓
           事件触发 → UI 更新
```

## 🎨 功能演示

### 创建项目流程

```
1. 按 P 键或点击按钮进入绘制模式
2. 右键拖动绘制项目区
3. 释放鼠标后弹出配置面板
4. 填写项目信息
5. 保存配置
6. 项目创建完成并显示在地图上
```

### 管理项目流程

```
1. 打开项目列表面板
2. 查看所有项目状态和进度
3. 点击项目定位到地图
4. 使用操作按钮管理项目
5. 实时查看状态更新
```
