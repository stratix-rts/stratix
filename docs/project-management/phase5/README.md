## 📝 关键功能

### 1. 批量操作
- **框选操作**: 拖动框选多个项目/任务区
- **右键菜单**: 选择"批量配置"
- **配置项**: 优先级、Agent模式、执行权限等
- **应用范围**: 可选择应用到哪些对象

### 2. Agent模式管理
- **模式切换**: OpenClaw ↔ LLM
- **权限说明**: 显示当前模式支持的操作
- **模式标识**: 项目区/任务区显示模式图标
- **智能提示**: 根据任务类型推荐模式

### 3. 项目管理
- **复制项目**: 复制配置和任务区方案
- **迁移项目**: 调整项目区位置和范围
- **删除项目**: 可选是否删除任务区和日志
- **项目模板**: 保存为模板供复用

### 4. AI重新规划
- **触发条件**: 用户微调蓝图后
- **优化内容**: 依赖关系、执行顺序
- **用户确认**: 展示优化方案供确认
- **应用更新**: 更新蓝图和执行计划

### 5. 手动新增任务区
- **添加方式**: 蓝图界面 / 右键菜单
- **AI识别**: 自动识别与现有任务的关联
- **依赖设置**: 可手动设置依赖关系
- **重新规划**: 可选触发AI重新规划

### 6. 快捷键
```
Ctrl+E   编辑配置
Ctrl+C   复制项目/任务
Ctrl+V   粘贴
Delete   删除
Ctrl+G   创建项目
Ctrl+A   全选
Esc      取消选择
```
