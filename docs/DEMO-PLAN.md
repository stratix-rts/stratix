## 0. 设计总纲（不可协商）

1. **风格**：扁平几何 + 霓虹点缀。全部视觉由代码绘制（Phaser Graphics / Container / Tween），**不新增位图/音频资产文件**。理由：worker 零资产可实现、任意分辨率无损、和现有 `appearance/character-composer` 体系兼容。
2. **交互三动词**：圈（框选）、点（点目标即下令）、看（导演镜头）。选中单位后**永远只给行动项不给配置项**；参数配置一律降级为预设三档（稳健/均衡/闪电）。
3. **总线铁律不变**：hud/world 互不引用，一切走 `core/types.ts` 契约；新文件头部写契约注释（职责/输入输出/禁止事项）。
4. **演示的脸和干活的脸分离**：`demo-mode` 开关隐藏全部工程件（raw json、task id 长串、时间戳、日志 tab），字号 +30%、信息密度下调。默认关（不影响现有开发习惯）。
5. **既有测试不回归**：tsc 零错、domain 测试全绿是每个任务的硬门槛。

## 1. 调色板与 Design Token（任务 v3.3-01）

`world/theme.ts` 与 hud 双 token 皮肤同步扩展，常量集中在 `world/visual-spec.ts`（新文件，唯一事实源）：

| 语义 | 色值 |
|------|------|

尺寸/时长规范：单位 hitbox 48px；hover 放大 1.1x；所有入场 ease `Back.Out` 250ms；所有退场 ease `Cubic.In` 300ms；摄像机移动 600ms `Cubic.easeInOut`。

## 2. 单位动画八态（任务 v3.3-02）

在 `unit-object.ts` / `character-composer` 之上加动画层（AnimationController per unit，随机相位避免整齐划一的假感）：

1. **待机三件套**（循环）：
   - 悬浮 bob：正弦 ±4px，周期 2s，相位随机
   - 眨眼：每 3-6s 随机触发，闭眼 120ms（眼睛压成横线）
   - 天线摆动：±5° 小幅旋转
2. **工作态**：身体前倾 8° + 高频微颤（±1px）；头顶**环形进度弧**（琥珀，0→360°）；每 1.5s 一次 squash-stretch（scaleY 0.9→1.05→1.0）
3. **卡住态**：整体灰度 50%，头顶红色 ❗ 每 2s 弹跳一次 + 身体同步抖动一下
4. **完成态**：squash → 原地跳 20px → 落地时脚下爆一圈**星尘粒子**（8-12 个小三角四散淡出）
5. **摸鱼态**（无任务空闲）：头顶依次冒 z→Z→Z 上升淡出，循环
6. **被选中**：脚下**旋转虚线选择环**（青色，直径 64px，2s/圈）
7. **hover**：放大 1.1x + 光标变 pointer + 底盘喷口微光增强
8. **被点击**：单击涟漪（白圈 200ms 扩散淡出）+ squash 一下

## 3. 气泡说话系统（任务 v3.3-03）

- **样式**：圆角气泡（黑底 85% 透明白字 13px，圆角 10px）+ 小尾巴指向单位头顶；最大宽度 160px 超长换行，最多 2 行超出省略
- **出入场**：入场 scale 0→1 Back.Out 250ms（锚点在尾巴）；出场上浮 10px + alpha→0 300ms；存活 4s 自动收
- **内容源（离线模板句库，不依赖网络/LLM）** `world/speech-templates.ts`：
  - 开工池：「这个我来！」「收到，开挖」「看我的」
  - 完成池：「搞定！」「下一个」「完工收工」
  - 报错池：「这有点不对…」「卡住了，求助」「这块有坑」
  - 被派活：「收到新任务」
  - 集火支援响应：「来了来了」「这就去」
  - 性格彩蛋池（20% 概率替换）：「咖啡呢？」「996 也是要充电的」「又是元气满满的一天」
- **频率控制**：同屏气泡 ≤ 3 个（新事件排队，旧的优先收）；同一单位 5s 内不重复冒泡
- **接线**：开工/完成/报错/派活事件从 core 总线事件驱动，world 只消费不生产

## 4. 点击与指令特效（任务 v3.3-04）

- **框选**（升级 `selection-box.ts`）：拖拽中——青色半透明填充 + 2px 霓虹边框 + 四角亮块；松手——边框收缩闪烁一次消失；命中的单位依次（每 40ms 一个）弹出选择环（波浪式点亮的仪式感）
- **下达指令**（点到任务点）：
  1. 每个选中单位脚下到目标点拉**流动虚线**（line dash offset 动画，青→目标色渐变），800ms 后淡出
  2. 目标点双重涟漪（两圈先后 300ms 扩散）
  3. 单位头顶统一冒「收到」类气泡（复用 §3）
- **任务点被认领**：任务卡 3D 翻转（背面灰色 → 正面亮色 + 图标）
- **任务完成插旗**：任务点上旗杆升起（0.5s）+ 旗面弹性展开（Back.Out）+ 插旗音效预留钩子（§10）
- **集火卡住单位**：选中群单位头顶同时冒「来了来了」，脚下位移脉冲一次

## 5. 地图：新大陆隐喻（任务 v3.3-05 / 06）

- **隐喻**：项目 = 岛屿，域 = 区域，任务 = 地块上的建筑。完成一片区域 → 点亮为「街区」。
- **地面**（05）：
  - 深色格网（`#1a2140`，格距 64px）+ 缓慢移动的横向扫描光带（每 12s 扫过一次，宽度 120px，8% 透明白）
  - 四角坐标刻度装饰 + 边缘渐晕
- **任务建筑三态**（05）：地基（灰描边空框）→ 施工中（脚手架纹理 + 小吊臂左右摆 15°）→ 完成（实心小塔，屋顶亮灯 + 完成瞬间窗户逐个点亮 200ms 间隔）
- **区域点亮**（05）：区域内全部建筑完成 → 底色 5%→12% 亮度渐变过渡 1s + 区域名浮字浮现
- **摄像机**（06）：拖拽平移 + 滚轮缩放 0.6-1.6x + 边界回弹；双击单位 = 跟随镜头（跟随中再次双击解除）；ESC 回全景
- **小地图**（06）：右下角 200×120px，岛屿轮廓 + 单位光点（按状态着色）+ 当前视野白框；点击小地图 = 镜头跳转；装饰：小地图外框描边 + 「MAP」角标
- **氛围彩蛋**（06）：地图边缘每 30-60s 漂过一朵慢速小云；每晚（真实时间 19-24 点）背景网格微微变暖——直播时段的隐藏彩蛋

## 6. 事件跑马灯 + 里程碑大字（任务 v3.3-07）

- **跑马灯**（hud widget，左下角）：最近 5 条，样式 = 图标 + 短句 + 相对时间（"刚刚/3 分钟前"）；分级配色：完成绿 / 报错红 / 派活蓝 / 里程碑金；新消息左侧滑入 250ms，旧消息下移，超 5 条最旧淡出
- **里程碑大字**：每 10 个完成任务触发一次，屏幕中央大字（金色，1.5s）：「第 10 个任务完成！」+ 轻微屏幕震动（camera shake 100ms 小幅度）——AREA CLEARED 式爽感
- 消息文案模板进 hud theme，中文，禁 AI 腔（过 humanizer-zh：无三段式/无装饰破折号）

## 7. 导演模式（任务 v3.3-08）

- 开关「🎬 导演」进 hud 顶栏；开启后：
  - 镜头自动订阅总线事件：开工/完成/报错 → 缓动到事件点（600ms），zoom 1.2x，停留 3s，回全景
  - 优先级：报错 > 完成 > 开工；同级取最新
  - 报错事件附加红色 vignette 脉冲（边缘红光呼吸 2 次）
  - 事件静默 > 8s：镜头缓慢巡视全图（漂移 pan）
- 关闭后完全恢复手动。**演示时主播只解说，不碰镜头。**

### 11.1 收口剧本（task_084）

`e2e-tests/demo-flow.e2e.mjs` —— fake CLI 模式（确定性）跑完整条演示链，44 条演示断言（A 段 11 / B 段 25 / C 段 8，另 1 条进程回收纪律断言）。

| 段 | 入口 | 覆盖 | 为什么要这一段 |
|----|------|------|----------------|
| A | dev 验收页（`src/app/dev/hello-loop.html`） | 框选 / 指令特效 / 卡住体态 / 集火 | 「卡住」态在生产入口不可达（全仓只有一处写 `error`，agent-link 未接主入口）—— 如实标注为产品缺口，不绕路 |

跑法：`node e2e-tests/demo-flow.e2e.mjs`（默认全跑三段）。排查用：`SX_DEMO_PHASES=A,B node e2e-tests/demo-flow.e2e.mjs` 只跑某几段、`--keep` 保留临时目录。全部走备用端口（7611/7612/7613/7614/7811/7812），用户实例的 7523 / 7524 / 9222 一个都不碰。
