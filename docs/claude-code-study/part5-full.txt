2462: 24. src/query/tokenBudget.ts： Agentic Loop 的预算控制阀
2463: 24.1 文件很小， 但位置很准

2471: 预算是否还够
2472: 还看：
2473: ·  最近增量token 是不是已经很少
2474: ·  连续继续几轮之后是不是已经进入 diminishing returns
2475: 这很有产品感。
2476: 因为真正糟糕的不是多花—点token， 而是 agent loop 在低收益状态下继续空转。

2484: .   completionEvent
