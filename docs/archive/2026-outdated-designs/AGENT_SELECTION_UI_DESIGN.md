# Agent 选中后 UI 交互功能重构方案

## 1. 背景与目标

### 1.1 项目背景

当前 Stratix RTS 系统已实现：
- Agent 单选/多选功能
- Zone 选中功能
- 基础事件通信（RTS ↔ UI）
- 左下角信息面板（CommandPanelV2）

### 1.2 问题现状

1. **功能缺失**：选中 Agent 后缺少操作按钮（聊天、配置、任务、停止）
2. **多选体验差**：多选时没有头像列表，操作不直观
3. **信息分散**：详情和技能通过 Tab 切换，信息不聚合
4. **聊天功能**：需要独立聊天弹窗，而非嵌入 TaskPanel

### 1.3 目标

重构 Agent 选中后的 UI 交互，提供类似 RTS 游戏的下选中操作体验：
- 单选：显示详细信息 + 操作按钮
- 多选：显示头像列表 + 批量操作
- 独立聊天弹窗
- 快速配置入口

## 3. 功能规格

### 3.1 操作按钮

| 按钮 | 单选 | 多选 | 功能描述 | 实现方式 |
|------|------|------|----------|----------|
| 💬 聊天 | ✅ | ✅ | 打开独立聊天弹窗 | 新建 AgentChatModal |
| ⚙️ 配置 | ✅ | ❌ | 打开角色编辑器 | 调用 openCharacterCreator |
| 📋 任务 | ✅ | ✅ | 打开任务面板 | 调用 TaskPanel |
| ⏹️ 停止 | ✅ | ✅ | 停止当前任务 | 调用后端 API |

### 3.2 头像列表（多选时）

- 显示所有选中 Agent 的头像
- 点击头像可取消该 Agent 的选中状态
- 显示"已选择 X 个 Agent"
- 提供"全选"和"取消"快捷操作

### 3.3 信息面板（单选时）

- **头像区域** (60x60)：显示 Agent 头像或类型图标
- **基本信息**：名称、类型、状态（在线/离线/忙碌）
- **技能列表**：显示 Agent 拥有的技能（最多4个）
- **任务状态**：当前任务名称 + 进度条

## 5. 实现计划

### Phase 1: 操作按钮（优先级 P0）

1. 在 CommandPanelV2 添加操作按钮区域
2. 添加 4 个按钮：聊天、配置、任务、停止
3. 添加按钮回调接口
4. 在 UIScene 实现回调处理

### Phase 2: 多选头像列表（优先级 P0）

1. 添加头像列表容器
2. 实现多选时头像列表显示逻辑
3. 点击头像取消选中功能
4. "全选"/"取消"功能

### Phase 3: 信息面板重构（优先级 P1）

1. 移除 Tab 切换
2. 聚合详情和技能到一个面板
3. 添加任务状态显示（任务名 + 进度条）
4. 优化布局和样式

### Phase 4: 独立聊天弹窗（优先级 P1）

1. 新建 AgentChatModal.vue
2. 复用 ChatPanel 逻辑
3. 支持独立窗口模式
4. 支持群聊模式

## 6. 验收标准

### 功能验收

| 功能 | 验收条件 |
|------|----------|
| 单选显示 | 选中 1 个 Agent 时，左下角显示详细信息 |
| 多选显示 | 选中多个 Agent 时，显示头像列表 |
| 聊天按钮 | 点击打开独立聊天弹窗 |
| 配置按钮 | 点击打开角色编辑器弹窗 |
| 任务按钮 | 点击打开任务面板 |
| 停止按钮 | 点击停止 Agent 当前任务 |

### 交互验收

| 场景 | 验收条件 |
|------|----------|
| 单选 → 多选 | 自动切换到多选模式显示头像列表 |
| 多选 → 单选 | 自动切换到单选模式显示详情 |
| 取消选中 | 点击空白区域或 ESC 清除选中状态 |

### 视觉验收

| 项目 | 验收条件 |
|------|----------|
| 布局位置 | 左下角，固定位置 |
| 响应式 | 窗口缩放时自动调整 |
| 主题适配 | 适配明暗主题 |

---

## 7. 风险与限制

1. **多选数量限制**：建议最大显示 10 个头像，超出显示"已选择 X 个"
2. **聊天弹窗复用**：ChatPanel 逻辑复杂，需要抽取通用部分
3. **停止任务 API**：需要确认后端是否支持批量停止
