## 🎯 功能清单

### 1. 性能监控面板 ✅

**位置：** TopBar右侧

**交互：** 点击展开

**包含数据：**
- 🎮 帧率统计（当前/最小/最大/平均 + 60帧历史图表）

- 💥 碰撞系统（检测次数/耗时/性能提升）
- 🎨 渲染系统（模式/密度/Draw Calls）
- 🖼️ UI系统（组件数量/事件队列）
- 💾 内存使用（可选）
- 🔧 调试工具控制（复选框）
- 💡 性能建议（自动提示）

**颜色编码：**
- 🟢 绿色：FPS ≥ 55（性能良好）
- 🟡 黄色：30 ≤ FPS < 55（性能警告）
- 🔴 红色：FPS < 30（性能严重）
