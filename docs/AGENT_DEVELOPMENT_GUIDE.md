# Agent 开发任务指南

## 任务概述

你将完成 Stratix RTS 项目中 **Agent 选中后 UI 交互功能重构**。这是一个类似 RTS 游戏的 Agent 操作界面优化任务。

## 项目背景

**Stratix** 是一个 AI Agent 管理系统，核心功能：
- 在 2D 画布上管理多个 AI Agent
- Agent 可以被选中、指挥、执行任务
- 选中 Agent 后需要显示操作面板

## 当前状态

✅ **已完成**：
- Agent 单选/多选功能（框选、Ctrl+1-9 编组）
- 基础事件通信（RTS ↔ UI）
- 左下角信息面板（CommandPanelV2）- 选中 agent 时显示基本信息

❌ **待完成**：
- 选中 Agent 后缺少操作按钮（聊天、配置、任务、停止）
- 多选时没有头像列表
- 信息通过 Tab 分散显示
- 缺少独立聊天弹窗

### 按钮功能

| 按钮 | 单选 | 多选 | 功能 |
|------|------|------|------|
| 💬 聊天 | ✅ | ✅ | 打开独立聊天弹窗 |
| ⚙️ 配置 | ✅ | ❌ | 打开角色编辑器弹窗 |

## 开发步骤

### 步骤 1: 添加操作按钮

1. 读取 `src/stratix-rts/ui/v2/CommandPanelV2.ts`
2. 找到 `create()` 方法，添加操作按钮区域
3. 在 `renderAgentDetail()` 后添加操作按钮渲染
4. 按钮需要响应点击事件

### 步骤 2: 添加回调接口

1. 在 CommandPanelV2 构造函数添加回调参数
2. 在 StratixRTSUIScene 传递回调实现
3. 实现基础的事件转发

### 步骤 3: 实现 App.vue 逻辑

1. 聊天按钮 → 打开独立聊天弹窗（Phase 4 实现）
2. 配置按钮 → 调用 `openCharacterCreator(characterId)`
3. 任务按钮 → 打开任务面板
4. 停止按钮 → 调用后端 API

### 步骤 4: 多选头像列表

1. 设计头像列表数据结构
2. 在 updateAgentInfo 时判断是单选还是多选
3. 多选时显示头像列表而非详细信息

## 重要约束

1. **保持向后兼容**：现有的 zone 选中功能不受影响
2. **使用现有组件**：优先复用已有的 UI 组件
3. **事件驱动**：通过 rtsEventBus 进行通信
4. **类型安全**：TypeScript 类型要完整
