### handleSave 流程
```typescript
async function handleSave() {
  const success = await charState.saveCharacter();
  if (success) {
    showToast('角色已保存', 'success');
    emit('created', charState.currentCharacter.value!); // 或 'updated'
  } else {
    showToast('保存失败', 'error');
  }
}
```
