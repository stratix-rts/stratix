### 渲染流程（来源：V1 CharacterPreview.ts + CharacterCreatorScene.ts）

```
1. composeCharacter(parts, {bodyType}) → { canvas }
2. 创建 Phaser CanvasTexture (SHEET_WIDTH × SHEET_HEIGHT)
3. 帧计算：
   animConfig = ANIMATION_CONFIGS[animation]  → { row, cycle }
   lpcRow = LOGICAL_TO_LPC[direction]
   dirRow = row + lpcRow
4. 用 setInterval 按 frameRate 推进当前帧
5. 每帧从 spritesheet 裁剪 → 设置到 sprite
```
