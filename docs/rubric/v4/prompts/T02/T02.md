function showToast(message: string, type = 'info') {

  toasts.value.push({ id, message, type });
  setTimeout(() => { toasts.value = toasts.value.filter(t => t.id !== id); }, 3000);
}

## 美学约束（A1-A8）— 必须遵守

### A1 间距规律性
- 使用 Spacing token（4, 8, 16, 24, 32, 48, 64），禁止硬编码 margin/padding
- 同层级元素间距一致
- 嵌套越深内间距越小（页面 32-48px → 区块 24px → 组件 12-16px → 元素 4-8px）

### A2 布局对齐
- flex/grid 布局，禁止 position: absolute 做正常布局
- 对齐属性必须显式声明（justify-content, align-items）

### A3 色彩与风格统一
- 颜色用 var(--ds-*)，禁止硬编码色值
- 同类元素相同样式
- 字号用 Typography token（xs=10, sm=12, md=14, lg=16, xl=20, 2xl=24, 3xl=32）
- 圆角用 Radii token（sm=2, md=4, lg=8, xl=16）
- 主色不超过 3 种

### A4 比例与尺寸
- 主要容器用经典比例（1:1.618 / 1:1.414 / 16:9 / 4:3 / 1:1）
- 图片/卡片声明 aspect-ratio
- 同类元素等尺寸，尺寸用 8px 基准

### A5 视觉层级与阅读流
- 字号层级 ≤ 3 层，字重配合层级（700→400→300）
- 1 个视觉焦点
- 阅读流：重要信息左上，CTA 在末端

### A6 简洁性
- CSS 选择器深度 ≤ 3
- 单组件样式属性 ≤ 15 条
- 重复样式提取共享 class

### A7 信息密度
- 留白 30-50%
- 单区域 ≤ 3 种信息类型
- 行间距 ≥ 字号 1.5 倍

### A8 对称与结构
- 表单标签统一方向
- 网格等宽等高
- 非对称需功能性理由
