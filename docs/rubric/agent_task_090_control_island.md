## 2. 关键设计决策

1. **56% 屏宽 与「距两角件 ≥40px」互相钳制 —— 取交集**：岛是**居中**的，两侧留边必须**同时**成立，
   约束方永远是更宽的那一侧（事件轨 260 > 小地图 200）。单侧最小留边 =
   角件贴边 16 + 角件宽 260 + 最小间距 40 = **316px**，故岛宽取
   `min(56%, 100% − 2×316px)`。实测：1280 宽 → 648px（50.6%）、1920 宽 → 1075px（56%）。
   **取舍说明**：1280 宽下 56%（717px）会压到事件轨上（岛左缘 281px < 事件轨右缘 276px + 40px），
   「零重叠 + ≥40px」是硬验收，56% 是软目标 —— 硬验收优先。此处已在
   `CONTROL_ISLAND_SIDE_INSET_PX` 里显式建模，不是隐式巧合。
2. **岛高 60px 而非 92px**：proposal 的 ≈92px 与「720p 下中轴可用高度 ≥85%」直接冲突 ——
   中轴 = 视口高 − 顶栏高 − 岛高，720p 下 720 − 40 − 92 = 588px（81.7% < 85%）。
   两条硬验收联立 → 岛高 ≤ 68px。取 **60px**（回放层 25 + 命令层 22 + 上下内边距 8 + 边框 2），
   实测中轴 620px（86.1%）。`targetHeightPx: 92` 保留在度量里作**设计参照**，
   但它不是实现值 —— 高度由内容自适应。
3. **高度「内容自适应」靠结构而非 magic number**：岛是 `flex-direction: column`，两层各自撑开，
   岛只有 `max-height: 100px` 封顶，没有 `height` 声明 —— 回放条或命令条变高时岛跟着长，
   长到 100px 封顶。断言脚本量的「回放层 / 命令层」两个数字就是这个自适应的证据。
4. **命令面板用 strip 变体而不是新组件**：`command-panel` 已是真组件（12 条命令、搜索框、
   任务标题草稿框、订阅链都在里面），重写一份会丢功能。新增一个 `variant="strip"` 属性，
   样式在**组件自己的 shadow 内**（外层 `::part()` 规则打不过内层 shadow 规则 ——
   结构变更必须住在组件里），默认变体行为完全不变（`default` 仍是老样子）。
5. **12 条命令一条不减**：strip 形态下 1 行显示 6 条，其余靠 `.sections` 横向滚动可达
   （`overflow-x:auto`）—— 窄屏（1024）下岛被钳到 392px，一屏只放得下 2 条，
   其余 4 条滚动可见；断言脚本对「放得下 / 放不下」两种分支分别断言
   （放不下时必须**可滚动**，不许消失）。
6. **提示信息从「行内提示」搬到 `title`**：strip 形态藏掉 `.cmd-hint` 行（否则一行放不下 6 条），
   命令详情（hint / reason）改挂按钮 `title`（tooltip），信息不丢。
7. **回放组件改成宿主可覆盖尺寸**：`day-replay` 原先在 `connectedCallback` 里
   `style.setProperty('--replay-strip-h', ...)` 强写自己的高度，宿主改不动（实测 CSS 自定义属性
   能穿过 `:host { all: initial }` 继承下去，但**组件自己写在 style 上的那一份优先级更高**）。
   改成组件只给默认折算值、宿主（控制岛）用 `--replay-strip-h: 14px` 覆盖。
8. **零新依赖、零资产**：图标仍是字形，热力条 / 按钮全是纯 CSS。
9. **顶栏 / 事件轨 / 小地图本体未动**：事件轨与小地图是 task_091 / task_096 的成果，
   本任务只**按它们的实测宽度给岛让位**（`CONTROL_ISLAND_SIDE_INSET_PX` 引用
   `MARQUEE_METRICS.maxWidthPx`）。

## 4. 未尽事项

- **1280 宽下岛宽只有 50.6%（648px），不是 56%**：56% 与「距事件轨 ≥40px」在 1280 宽下不可兼得，
  本任务选了硬验收（零重叠 + 间距）。若要恢复 56%，需把事件轨宽度口径调小（≥200px）——
  属于 task_091 的口径，需与设计侧确认后再改。
- **strip 形态藏掉了通知列表**（`.notices`）：岛内一行放不下；顶栏的通知徽标仍在，
  通知本体在侧边栏面板可见。若认为「岛内也要能看到通知」，需再开一个折叠入口。
- **窄屏（容器宽 ≤700px）下岛退化为文档流区块**（不再贴底居中）—— 这是既有的
  `@container` 兜底路径，本任务未改其行为，只保证它不与新度量冲突。
- **碰撞断言脚本需要真浏览器**：jsdom 无排版引擎，bounding box 全是 0 —— 脚本依赖
  Playwright（仓库已有依赖，未新增），跑前需起 vite dev（端口以启动日志为准）。
